## File Dependencies

```
prepare_dataset.py
    ↓ Creates: train/ and val/ directories
    ↓
train_tensorflow.py
    ├─ Inputs: train/ and val/ directories
    ├─ Creates: model_tensorflow.h5
    └─ Creates: class_indices.json
    ↓
model_tensorflow.py
    ├─ Inputs: model_tensorflow.h5
    ├─ Inputs: class_indices.json
    └─ Produces: JSON predictions
    ↓
Backend (app.py)
    ├─ Imports: from model_tensorflow import predict_image_tensorflow
    └─ Uses: model_tensorflow.py for inference

validate_training.py
    ├─ Checks: model_tensorflow.h5 exists
    ├─ Checks: class_indices.json exists
    └─ Checks: train/ directory exists

test_inference.py
    ├─ Loads: model_tensorflow.h5
    ├─ Loads: class_indices.json
    └─ Tests: On training images from train/ directory

model_switcher.py
    ├─ Reads: model_config.json
    ├─ Uses: model_tensorflow.py or model.py
    └─ Updates: model_config.json
```
